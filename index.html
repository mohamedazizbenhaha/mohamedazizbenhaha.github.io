    Things I'm building.

    Life OS

    Natural language in, validated actions out

    My personal operating system, on my phone every day. It started as a gym log and keeps growing: training, notes, tasks, reminders, calendar, groceries, and next, money. Type or speak one sentence and an AI turns it into validated actions, with one-tap undo. Each module is its own app; they share one sync key and read each other's data, never write it.

    • PWA
    • LLM actions
    • Speech input
    • Netlify Functions
    • Cloud sync

    Create Life

    A personal AI that improves itself

    An open architecture for a personal AI: a local LLaMA model, voice recognition that trusts only its owner's voice, a self-evolution loop that evaluates and updates its own modifiable code, and core principles it can never rewrite. Every service runs in Docker, every change is logged.

    • LLaMA
    • Voice ID
    • Self-modification
    • Docker Compose
    • Flask

    Thesis ecosystem

    Tools for the whole PhD journey, from subject to defence

    Four connected tools for students and supervisors: find a subject and a supervisor, publish the thesis, question your own sources, and run the research itself. Microservices deployed on Kubernetes with Helm.

    • Next.js
    • PostgreSQL
    • Prisma
    • Kubernetes
    • Helm

    GreenWaterGuard · PhD

    Microbial fuel cells used as living sensors, an IoT acquisition box, and machine learning that runs on the device to read water quality in real time. Franco-Tunisian project (PHC Utique 2025–2027) between Innov'COM, Sup'Com, and the Ampère lab, École Centrale de Lyon.

    • Embedded ML
    • IoT–Cloud
    • ESP32
    • 3D-printed reactor

    Water-quality gateway firmware
